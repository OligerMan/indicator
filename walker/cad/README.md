# CAD ходока

Пока пусто. Рекомендуется Onshape: `onshape-to-robot` даёт URDF/MJCF с массами и инерциями.

План деталей:
- узел бедра: кронштейн двух соосных STS3215 с опорными подшипниками;
- втулки звеньев под трубки 10×8 / 12×10 (зажим + эпоксидка);
- шарнир стопы, стопа TPU;
- вставка-заглушка модуля отведения (стадия 1) и кронштейн серво отведения (стадия 2);
- клин развала 10–15°;
- шасси: отсек аккумулятора внизу, место под Pi, посадочная сетка под светильник, груз-макет.
