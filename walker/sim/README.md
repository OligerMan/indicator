# Симуляция и обучение

Пока пусто. План:

```
sim/
  models/        MJCF: параметрическая модель (B0), потом экспорт из CAD (onshape-to-robot)
  envs/          среды для MuJoCo Playground: стойка, ходьба по команде
  actuators/     модель STS3215 по результатам идентификации (B1)
  train.py       обучение PPO
  export.py      политика → ONNX для walker/brain
  runs/          логи и чекпойнты (в .gitignore)
```

Первый шаг (B0): параметрическая MJCF — корпус с массой светильника, 4 пятизвенника с
параметрами L1, L2 и развалом. Ответить на вопросы: стоит ли, какие моменты в стойке,
приседе и рыси, какие длины звеньев выбрать.

Окружение: WSL2 + JAX CUDA — [docs/wiki/dev-setup.md](../../docs/wiki/dev-setup.md).
