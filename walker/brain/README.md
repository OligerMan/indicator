# «Мозг» ходока (Raspberry Pi Zero 2 W)

Пока пусто. План (этапы B2, B4, C1):
- цикл 50 Гц: IMU → наблюдения → политика (onnxruntime) → sync write в серво → sync read;
- безопасность: пределы углов, температура серво, программное отключение момента,
  аппаратная аварийная кнопка;
- телеметрия по Wi-Fi на ПК (UDP), приём команд верхнего уровня;
- UART к светильнику: тот же текстовый протокол ([docs/lamp/protocol.md](../../docs/lamp/protocol.md)).

Референс по устройству — Open Duck Mini Runtime.
