# Светильник — механика

## Компоновка
Две панели 320×160 мм стоят вертикально, спинами друг к другу, «бутербродом». Между ними
зазор ~40 мм под электронику: ESP32, три понижающих преобразователя, IMU, разводка.
```
   вид сбоку (торец)             вид спереди
   ┌─┐      ┌─┐                  ┌──────────────────────────┐
   │П│ ESP │П│                   │        панель 0          │ 160
   │0│ DCDC│1│                   │       128×64 px          │
   │ │ IMU │ │                   └──────────────────────────┘
   └─┴─────┴─┘                               320
   ← ~40 мм →   + толщина панелей
```
Итоговый габарит (оценка): 320 × 160 × (40 + 2 × толщина модуля ≈ 15–20) ≈ 75–80 мм.
Точные значения — в [measurements.md](measurements.md) после сборки.

## Рамка
- Материал: PETG (жёсткость, термостойкость у преобразователей).
- Стол P1S 256×256 мм меньше длины панели → рамка из 2–3 частей: два торца и
  продольные балки, соединение винтами M3 во вставки (heat-set inserts) или «ласточкин хвост».
- Панели крепятся к рамке своими отверстиями M3 (у модулей обычно 4–8 шт.; проверить,
  если стоят магниты — снять или использовать).
- Торцы: вентиляционные щели напротив преобразователей, вывод разъёма питания,
  USB-доступ к ESP32 (или только OTA).
- **IMU жёстко к рамке** (винты, без мягких прокладок): стук должен доходить до датчика.
  Ось датчика записать в `config.h` (`kImuAxisMap/Sign`).
- Нижний торец — посадочное место под подставку сейчас и под шасси ходока позже
  (одинаковая сетка отверстий, см. [walker/integration.md](../walker/integration.md)).

## Удары
Стучат по рамке/торцу, не по светодиодам: SMD-светодиоды P2.5 легко сбить. Варианты:
- торцевые накладки из TPU — «куда стучать»;
- выступ рамки на 2–3 мм над плоскостью панели по периметру.

## Рассеиватель (по желанию)
Режим «пятна» как в v1: съёмная накладка из матового акрила или плёнки на расстоянии
5–15 мм от панели. Крепление на магнитах к рамке. Проверить на собранной рамке, нужно ли.

## Подставка
Простая печатная подставка с широким основанием (центр тяжести высоко). Масса панелей
~0,4–0,6 кг каждая, взвесить.
