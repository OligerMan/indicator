# Светильник — первый запуск

Порядок важен: сначала выясняем, что за железо, потом включаем по одной панели на малой яркости.

## 0. Опознать железо (до включения)
- [ ] **Чипы драйверов** на обороте панели (самые многочисленные микросхемы): записать
      маркировку в [measurements.md](measurements.md).
  - ICN2037, FM6124, FM6126A, ICN2038S, MBI5124, DP3246 и простые сдвиговые регистры —
    поддерживаются (`kShiftDriver` в `config.h`).
  - **ICN2053, FM6353, ICN2153, SM1620B, MBI5153 и другие S-PWM — не поддерживаются**
    этой библиотекой. Тогда см. `esphome/esp-hub75` или другие панели.
- [ ] **Декодер строк** (маленькие микросхемы у края): 74HC138 / ICN2013 / RUC7258 / SM5266P.
- [ ] Маркировка разъёма: HUB75E (есть E на выводе 8).
- [ ] Модуль на DevKitC: `ESP32-WROOM-32` или `ESP32-WROVER` (надпись на жестяном экране).
      WROVER → переназначить CLK (16) и D (17) в `config.h`.

## 1. Питание без нагрузки
- [ ] Выставить понижающие преобразователи на 5,1 В без нагрузки.
- [ ] Проверить полярность на разъёмах питания панелей (VH4: красный +5 В).

## 2. Одна панель, тест узоров
- [ ] Прошить: `pio run -e panel_test -t upload`, открыть `pio device monitor`.
- [ ] В логе: `refresh ... Hz, DMA used ..., DMA free ...` — записать.
- [ ] Подключить шлейф к панели 0, включить питание панели.
- [ ] Шаги (переключение `n`, пауза `p`, яркость `+`/`-`):

| Шаг | Нормально | Если не так |
|---|---|---|
| красный/зелёный/синий | чистый цвет по всей панели | цвета перепутаны → поменять R/G/B пины |
| row scan | одна линия идёт сверху вниз по всем 64 строкам | линии парами/пропуски → E-пин, A–D; 1/32 vs 1/16 |
| column scan | одна вертикальная линия по всей ширине | смещение на 1 px → `kClockPhase` |
| gradients | плавные полосы, 64 ступени | тёмная часть рваная → нормально для 6 бит; мусор → драйвер (`kShiftDriver`) |
| orientation | красный — левый верх, зелёный — правый верх | запомнить, как панель стоит |

- [ ] Ничего не светится вообще: проверить OE/LAT/CLK, `kShiftDriver = 2` (FM6126A
      требует инициализации).

## 3. Две панели
- [ ] Подключить панель 1 шлейфом от выхода панели 0.
- [ ] Повторить тест: «panel 1 …» должны гореть на второй панели.
- [ ] Шаг «orientation» на собранном «бутерброде»: подобрать `kFaceFlipX/Y` и
      `kFaceChainPos` так, чтобы при взгляде на каждую сторону красный был слева вверху.

## 4. Белый экран
- [ ] Шаг «both white» на яркости 40 → 100 → 160, мультиметром/INA226 — ток по 5 В каждой
      панели. Смотреть на просадку напряжения (не ниже 4,8 В).

## 5. Основная прошивка
- [ ] `include/secrets.h` из примера (или работать через точку доступа).
- [ ] `pio run -e lamp -t upload`, в консоли `status`, `scenes`, `scene speckles`.
- [ ] Без IMU: `tap`, `gesture double` — проверить меню.
- [ ] С IMU: стук по столу рядом не должен срабатывать, стук по рамке — должен.
      Пороги — `Taps.h`.

## 6. Калибровка тока
- [ ] Сцена `solid`, `limit 40000` (временно без лимита), `bright 64`.
- [ ] Чёрный (`color 0 0 0`): ток → `kIdleCurrentMa`.
- [ ] Белый (`color 255 255 255`): ток I_w.
      `kMaPerChannelFull = (I_w − idle) / (2 × 8192 × 3 × 64/255)`.
- [ ] Проверить на `color 109 0 204` и `scene speckles`: оценка из `status` ≈ измерение (±15%).
- [ ] Вернуть лимит, записать коэффициенты в `config.h` и [measurements.md](measurements.md).
