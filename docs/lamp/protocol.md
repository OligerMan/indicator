# Светильник — протоколы управления

## 1. Текстовые команды
Один формат для всех каналов:
- USB-консоль (115200, `pio device monitor`);
- UART-связь GPIO32/33 (115200) — будущий «мозг» ходока;
- HTTP `POST /api/cmd`, тело — строка команды.

Одна команда на строку, слова через пробел, регистр не важен. Ответ — текст, заканчивается
переводом строки; ошибка начинается с `error:`.

| Команда | Аргументы | Действие |
|---|---|---|
| `help` | — | список команд |
| `status` | — | сцена, яркость (запрошенная/применённая), лимит и оценка тока, fps, частота обновления, память, статистика стрима |
| `scenes` | — | список сцен `индекс имя`, текущая помечена `*` |
| `scene` | `<имя\|индекс>` | переключить сцену |
| `bright` | `0..255` | запрошенная общая яркость |
| `limit` | `мА 0..40000` | лимит тока панелей |
| `color` | `r g b` (0..255) | сплошной цвет, переключает на `solid` |
| `gesture` | `single\|double\|triple\|many` | имитация жеста |
| `tap` | — | имитация одного стука (проходит через секвенсор) |

Пример `status`:
```
scene speckles
bright 96 applied 71
limit_ma 6000 estimate_ma 5990
fps 30.0 refresh_hz 90
heap 101234 dma_heap 45678
stream_packets 0 errors 0
```

Разбор — `lib/indicator_core/src/Command.cpp`, тесты — `test_command_*`.

## 2. HTTP
| Метод | Путь | Ответ |
|---|---|---|
| GET | `/` | веб-страница управления |
| POST | `/api/cmd` | тело = команда, ответ = текст |
| GET | `/api/status` | то же, что `status` |

Адрес: `http://indicator.local` (mDNS) или IP из консоли. Без Wi-Fi-настроек — точка
доступа `indicator-setup` / `indicator`, адрес `http://192.168.4.1`.

## 3. UDP-поток кадров (порт 7777)
Каждая датаграмма несёт целые строки одной стороны. Первый пакет переключает светильник
в сцену `stream`, через 3 с без пакетов он возвращается к прошлой сцене.

| Смещение | Размер | Поле | Значения |
|---|---|---|---|
| 0 | 1 | магия | `'I'` |
| 1 | 1 | магия | `'F'` |
| 2 | 1 | версия | `1` |
| 3 | 1 | формат | `0` = RGB565 LE, `1` = RGB888 |
| 4 | 1 | сторона | `0` лицо, `1` спина, `2` обе |
| 5 | 1 | y0 | первая строка 0..63 |
| 6 | 1 | rows | число строк, y0+rows ≤ 64 |
| 7 | 1 | флаги | бит 0 — последний пакет кадра |
| 8 | … | пиксели | rows × 128 × (2 или 3) байт, построчно |

Рекомендуемые размеры, чтобы влезть в MTU 1500: RGB565 — 5 строк (1288 байт),
RGB888 — 3 строки (1160 байт). Кадр одной стороны в RGB565 = 13 пакетов.

Отправитель на ПК — `tools/stream_frames.py`. Разбор — `FramePacket.cpp`, тесты — `test_frame_packet_*`.

## 4. Планы
- Бинарный протокол для UART, если текста не хватит по скорости (кадры по UART не
  планируются: 115200 бод ≈ 11 КБ/с).
- Сообщения от светильника наверх (события стука) — для ходока: `event tap double` и т.п.
