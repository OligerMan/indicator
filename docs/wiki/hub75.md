# HUB75: как устроены панели

## Сигналы
| Вывод | Назначение |
|---|---|
| R1 G1 B1 | данные цвета для верхней половины |
| R2 G2 B2 | данные для нижней половины |
| A B C D E | номер пары строк (5 бит → 32 пары для 64 строк) |
| CLK | тактирование сдвигового регистра |
| LAT | защёлка: сдвинутая строка переносится на выходы |
| OE | гашение (активный низкий): пока высокий — панель тёмная |
| GND | несколько выводов земли |

У панели нет своей памяти кадра: контроллер постоянно, сотни раз в секунду, перебирает строки
и для каждой строки несколько раз выводит битовые плоскости цвета (BCM). Поэтому на
ESP32 нужен DMA-буфер, где подготовлены все плоскости.

## Развёртка
«1/32» у панели 128×64: одновременно светятся строки `y` и `y+32`. Встречаются панели с
«нестандартной» развёрткой (1/8, 1/16 при 64 строках, «четырёхсканные»): у них пиксели
идут не по порядку, лечится картой пикселей (VirtualMatrixPanel в библиотеке).

## Чипы драйверов
- **Простые сдвиговые регистры** (ICN2037, FM6124, MBI5124 и т.п.) — работают с любым контроллером.
- **С регистром конфигурации** (FM6126A, ICN2038S) — нужна инициализация при старте
  (`driver = FM6126A`), иначе панель тёмная.
- **S-PWM с памятью** (ICN2053, FM6353, ICN2153, MBI5153, SM1620B …) — сами делают ШИМ, нужен
  другой протокол. ESP32-HUB75-MatrixPanel-DMA их не поддерживает.

## Декодеры строк
74HC138 (обычный, по адресу A–E), ICN2013/RUC7258/SM5266P/DP3246 — сдвиговые или со своими
особенностями. Настраиваются через `line_decoder` в библиотеке.

## Питание
- 5 В, ток зависит от картинки: белый экран — максимум, чёрный — ток холостого хода.
- Питание подаётся на каждую панель отдельно, толстыми проводами (разъём VH4).
- При просадке напряжения синий гаснет первым, картинка «желтеет».

## Частые проблемы
| Симптом | Причина |
|---|---|
| Светятся строки парами / повторяется половина | не подключён или не задан E, неверная развёртка |
| Изображение сдвинуто на 1 пиксель, «двоение» | фаза тактирования (`clkphase`) |
| Мерцание, «снег» | длинный шлейф, уровни 3,3 В, мало земли, частота I2S |
| Панель тёмная, но ток есть | FM6126A без инициализации |
| Мусор вместо картинки | S-PWM-драйвер или неверный драйвер |
| Цвета перепутаны | распиновка RGB у конкретной панели |
