# Печать на Bambu Lab P1S

## Материалы
| Материал | Где | Примечания |
|---|---|---|
| PETG | рамка светильника, кронштейны, корпус шасси | жёстче к нагреву, чем PLA; не течёт у преобразователей |
| PLA | прототипы, подставки | быстро, точно; плывёт от тепла (>55 °C) |
| TPU 95A | стопы, накладки «куда стучать», демпферы | медленно, без AMS (прямая подача) |
| PA-CF / PET-CF | нагруженные узлы ног | **нужно закалённое сопло**: штатное у P1S — нержавейка |

## Размеры
- Стол 256×256×256 мм. Панель 320 мм → рамку делить на части.
- Соединения: винты M3 во вставки (heat-set), «ласточкин хвост», штифты.

## Допуски (начальные, подобрать тестовой печатью)
| Посадка | Зазор |
|---|---|
| Подшипник в корпус (плотно) | −0,05…0 мм по диаметру |
| Вал в отверстие (свободно) | +0,2…0,3 мм |
| Вставка M3 (heat-set) | по спецификации вставки, обычно Ø 4,0–4,2 |
| Трубка 10 мм во втулку под эпоксидку | +0,2 мм |

## Прочность
- Ориентация: слои поперёк нагрузки на изгиб — слабое место. Кронштейны серво печатать так,
  чтобы усилие шло вдоль слоёв.
- 4–5 периметров, заполнение 30–50% гироид для нагруженных деталей.
- Отверстия под оси — подшипники, а не пластик по металлу.
