# Шинные серво Feetech STS

## Протокол
- Полудуплексный UART, одна сигнальная линия на все серво (плюс питание и земля).
  Скорость по умолчанию 1 Мбит/с.
- Пакет: `FF FF ID LEN INSTR PARAMS… CHECKSUM`.
- Инструкции: PING, READ, WRITE, SYNC WRITE (одна посылка — цели для всех), SYNC READ
  (у STS — чтение с нескольких серво одним запросом).
- Регистры (таблица памяти): ID, скорость шины, пределы углов, режим, цель положения,
  скорость, ускорение, текущие положение/скорость/нагрузка/напряжение/температура,
  включение момента.

## Подключение к Pi / ПК
- Готовый USB-адаптер (Feetech FE-URT, Waveshare Bus Servo Adapter) — проще всего.
- UART Pi + полудуплексная схема (74HC126 или адаптер) — меньше задержка, чем USB.
- Библиотеки: `scservo_sdk` / `feetech-servo-sdk` (Python), LeRobot (пример FeetechMotorsBus
  с sync read/write).

## Настройка перед сборкой
1. Подключать **по одному** серво, назначать уникальный ID (с завода у всех ID = 1).
2. Записать ID на корпус.
3. Задать пределы углов под механику ноги (защита от самоповреждения).
4. Откалибровать нулевое положение (смещение) после сборки.

## Особенности
- Встроенный регулятор положения: коэффициенты P/D/I в регистрах, их стоит
  зафиксировать одинаковыми и учесть в модели актуатора.
- Нагрузка (`present load`) — оценка по ШИМ/току, не точный момент.
- Перегрев при длительном удержании под нагрузкой: следить за температурой, класть робота.
- Люфт шестерён ~0,5–1°: учитывать в рандомизации.
- Варианты 7,4 В и 12 В с разными редукторами отличаются моментом и скоростью — не смешивать.

## Идентификация (этап B1)
- Ступенчатый отклик без нагрузки и с грузом на рычаге.
- Зависимость момента от ошибки положения и скорости.
- Трение, люфт, задержка шины.
- Результат — параметры модели актуатора для MuJoCo (см. опыт Open Duck Mini).
