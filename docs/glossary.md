# Глоссарий

| Термин | Значение |
|---|---|
| **HUB75 / HUB75E** | стандарт разъёма и сигналов LED-панелей: 6 линий цвета (R1G1B1 R2G2B2), адрес строк A–D(E), CLK, LAT, OE. «E» нужна для 64 строк |
| **P2.5** | шаг пикселя 2,5 мм |
| **Развёртка 1/32** | одновременно светятся 2 строки из 64 (верхняя и нижняя половины), строки перебираются 32 раза за кадр |
| **BCM** | binary code modulation — яркость канала задаётся временем свечения по битам; больше бит = больше памяти |
| **OE** | output enable — сигнал гашения панели; через его длительность регулируется общая яркость |
| **DMA** | прямой доступ к памяти: периферия ESP32 сама выводит буфер на панели без CPU |
| **CIE 1931** | кривая восприятия яркости; драйвер переводит значения 0–255 в «линейное» время свечения |
| **Сцена** | режим светильника (в v1 — «state») |
| **Жест** | серия стуков: одиночный, двойной, тройной |
| **DOF** | степень свободы (сустав) |
| **Пятизвенник** | нога из двух пар звеньев, оба мотора в корпусе, стопа — общий шарнир |
| **Отведение (abduction)** | поворот ноги в сторону от корпуса |
| **IK** | обратная кинематика: из положения стопы — углы суставов |
| **RL** | обучение с подкреплением |
| **PPO** | стандартный алгоритм RL для управления роботами |
| **sim2real** | перенос политики из симуляции на реальное железо |
| **Рандомизация** | случайное изменение параметров симуляции при обучении, чтобы политика не зависела от неточностей модели |
| **MJCF** | формат модели MuJoCo (XML) |
| **ONNX** | формат для запуска обученной сети где угодно (onnxruntime) |
| **BMS** | плата защиты/балансировки литиевого аккумулятора |
| **3S2P** | 3 элемента последовательно, 2 параллельно |
| **OTA** | обновление прошивки по сети |
