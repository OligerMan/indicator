# 0004. Один текстовый протокол для всех каналов

- Статус: принято
- Дата: 2026-09-25

## Контекст
Управлять светильником нужно с USB-консоли (отладка), по Wi-Fi (телефон) и по UART (Pi ходока).

## Решение
Строковые команды (`scene speckles`, `bright 80`, `color 109 0 204`, …). Разбор — в переносимом
ядре (`Command.cpp`), с тестами. HTTP `POST /api/cmd` принимает ту же строку. Потоковые данные
(кадры) идут отдельным бинарным UDP-протоколом.

## Альтернативы
- JSON/REST — удобнее для веба, но тяжелее для UART и ручной отладки.
- MQTT — позже, как ещё один транспорт поверх тех же команд.

## Последствия
- Любую функцию можно проверить из консоли.
- Если для UART понадобится скорость — отдельный бинарный режим, а не замена текста.
