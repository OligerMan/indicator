# 0005. Приводы ног — Feetech STS3215 12 В

- Статус: принято
- Дата: 2026-09-25

## Контекст
Нужны управляемые суставы (включая колено) для RL-походки. Масса робота ~3–3,3 кг.
Для переноса из симуляции нужны обратная связь и предсказуемость.

## Решение
Шинные серво Feetech STS3215, вариант 12 В (30 кг·см в стопоре, ~10 кг·см номинал, 55 г):
12-бит энкодер, положение/нагрузка/температура по шине.

## Альтернативы
- Шаговые двигатели — тяжёлые (NEMA17 ~300 г), без управления моментом, теряют шаги на ударах.
- Обычные ШИМ-серво (MG996R, DS3218) — нет обратной связи, мёртвая зона, плохой перенос из симуляции.
- BLDC-приводы (CyberGear, moteus) — тяжелее и дороже для этого масштаба.
- Более мощные Feetech (40–50 кг·см) — запасной вариант, если B0/B1 покажут нехватку момента.

## Последствия
- Серво питаются от 3S напрямую.
- Нужна идентификация серво на стенде (B1).
