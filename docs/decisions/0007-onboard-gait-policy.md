# 0007. Походка на борту, верхний уровень — можно удалённо

- Статус: принято
- Дата: 2026-09-25

## Контекст
Можно считать всё на ПК/телефоне по Wi-Fi, а робот будет только отправлять данные. Но цикл
баланса на 50 Гц чувствителен к задержке, а у Wi-Fi бывают провалы на 100+ мс.

## Решение
- Политика походки (MLP, ONNX) работает на Pi Zero 2 W, 50 Гц.
- ПК/телефон: команды верхнего уровня, телеметрия, логи, тяжёлые алгоритмы (зрение, голос).
- Для прототипа удалённый запуск политики допускается как эксперимент.

## Альтернативы
- Всё на ПК — провалы связи роняют робота.
- Всё на ESP32-S3 — возможно для маленькой сети, но неудобно разрабатывать.

## Последствия
- На борту нужен Pi Zero 2 W и своя программа «мозга» (`walker/brain`).
