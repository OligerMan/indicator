# Ходок — кинематика ног

## Зачем ноге 3 степени свободы
Точка стопы в пространстве — три координаты, поэтому для полного управления нужно
три сустава:
- **бедро вперёд-назад + колено** — стопа в продольной плоскости: длина и высота шага;
- **отведение бедра** — стопа поперёк: шаг вбок, поворот на месте без проскальзывания,
  наклон корпуса, парирование бокового толчка, неровный пол.

У нашего корпуса слабое направление — поперечное: он узкий (~8 см) и высокий (панели
160 мм + ноги). Поэтому отведение в итоге нужно, но для начала без него можно обойтись.

## Варианты
| Вариант | Серво | Умеет | Минусы |
|---|---|---|---|
| А. 3DOF последовательный | 12 | всё | дороже, тяжелее, больший ток, дольше обучать |
| Б. 2DOF последовательный, фиксированный развал | 8 | вперёд/назад, рысь, поворот разной длиной шага | поворот с проскальзыванием, поперёк держит только широкой стойкой |
| **В. 2DOF пятизвенник, фиксированный развал** | 8 | как Б | больше шарниров, замкнутая цепь в модели |

**Выбрано: В на стадии 1, затем А (В + модуль отведения) на стадии 2** (ADR 0006).

## Пятизвенник
```
        M1 ⊙ M2          ← два серво соосно в бедре (оба в корпусе)
          /  \
      L1 /    \ L1       ← верхние звенья, по одному на серво
        /      \
        \      /
      L2 \    / L2       ← нижние звенья, шарнир в стопе
          \  /
           ●  стопа
```
- Оба мотора в корпусе → нога лёгкая (только трубки и шарниры), малая инерция — это
  хорошо и для динамики, и для переноса из симуляции.
- Вертикальную нагрузку держат **оба** серво, а не одно коленное: при нашем
  моменте впритык это главный плюс.
- «Колено» управляемо: угол между звеньями задаётся комбинацией двух углов моторов.
  Удобные обобщённые координаты: `θ_mean = (θ1+θ2)/2` — направление ноги (как бедро),
  `θ_diff = θ2−θ1` — длина ноги (как колено).
- Недостатки: рабочая зона меньше, есть особые положения (звенья вытянуты в линию) —
  ограничиваем диапазон программно.

Референсы: Stanford Doggo, Ghost Minitaur (ссылки в [references.md](../references.md)).

### Предварительная геометрия (уточнить в B0)
| Параметр | Значение | Комментарий |
|---|---|---|
| L1 (верхнее звено) | 60–70 мм | |
| L2 (нижнее звено) | 110–130 мм | |
| Высота бедра в стойке | ~150 мм | |
| Развал ног (стадия 1) | 10–15° наружу | печатный клин в узле бедра |
| Ширина колеи по стопам | 150–200 мм | корпус ~80 мм |
| База (перед–зад) | ~300 мм | по длине панели |

### Грубая проверка момента
Масса 3 кг, рысь: на опорную ногу ~15 Н (в динамике до ~30 Н). При L1 = 65 мм и
типовом угле звеньев момент на каждом серво порядка 0,5–1 Н·м. Номинал STS3215 (12 В)
~1 Н·м, в стопоре ~2,9 Н·м. Для 2DOF последовательной ноги на колене вышло бы ~1–2 Н·м
на одном серво. Точный расчёт — в симуляции (B0): записать пиковые и средние моменты
по суставам для стойки, приседа и рыси.

## Стадия 2: модуль отведения
```
корпус ─ [вставка | серво отведения] ─ блок бедра (M1, M2) ─ нога
```
- Вставка на стадии 1 имеет габарит и точки крепления серво + кронштейна, и ту же
  массу (грузик), чтобы центр масс и модель не менялись.
- Ось отведения — вдоль длинной стороны корпуса, по возможности ближе к плоскости ноги
  (меньше плечо).
