# CAD светильника

Пока пусто. Появится после замеров панелей (толщина модуля, расположение отверстий M3).

Соглашения:
- Имена: `lamp-<деталь>-v<N>` (например, `lamp-frame-end-v1`).
- Хранить исходник (ссылка на Onshape / .f3d / .FCStd) и экспорт `.step` + `.3mf` для печати.
- В `.3mf` — профиль печати (материал, периметры, заполнение).

Детали (план): торцы рамки ×2, продольные балки, крепление IMU, отсек электроники,
подставка с посадочной сеткой (та же, что на шасси ходока), накладки TPU, рассеиватель (опц.).
Требования — [docs/lamp/mechanics.md](../../docs/lamp/mechanics.md).
