# CLAUDE.md — Индикатор v2

Контекст для Claude Code (и для людей) при работе с этим репозиторием.

## Что это
Реплика «индикатора» из мультфильма «Тайна третьей планеты»: коробочка, которая меняет цвет
«от настроения», а если её стукнуть — становится фиолетовой в крапинку. v1 (светодиодная лента +
Arduino + MPU6050) лежит в `legacy/indicator-v1/`. v2 — две HUB75-панели 128×64 и, в перспективе,
ноги с RL-походкой.

Проект разделён на **два трека**, которые позже объединяются (docs/decisions/0001):
1. **Светильник** (`lamp/`) — сейчас в работе. ESP32 + две панели, стуки, наклон, Wi-Fi.
2. **Ходок** (`walker/`) — позже. Стадия 1: 2DOF-пятизвенник, стадия 2: 3DOF. Шинные серво
   Feetech STS3215, RL в MuJoCo Playground.

## Карта репозитория
```
lamp/firmware/          PlatformIO-проект прошивки светильника (ESP32, Arduino)
  include/config.h        ВСЕ пины, геометрия панелей, лимиты тока — только здесь
  lib/indicator_core/     переносимое ядро без Arduino: сцены, стуки, наклон, лимит тока,
                          команды, UDP-пакеты. Компилируется и на ПК (тесты).
  src/hw/                 адаптеры железа: Display (HUB75), Imu (MPU6050)
  src/app/                App — склейка ядра и железа, выполнение команд
  src/net/                Wi-Fi, веб-страница, /api/cmd, OTA, UDP-поток кадров
  src/bringup/            тест панелей (env panel_test)
  test/test_core/         Unity-тесты ядра (env native)
lamp/cad/               CAD светильника (рамка, крепления)
walker/                 ходок: cad/, sim/ (MJCF, обучение), firmware/, brain/ (Pi)
tools/                  утилиты для ПК (стрим кадров по UDP и т.п.)
docs/                   документация: см. docs/README.md
legacy/indicator-v1/    исходники v1, справочно, не менять
```

## Команды
Из `lamp/firmware/` (pio: `~/.platformio/penv/Scripts/pio.exe`, в PATH его нет):
- `pio test -e native` — тесты ядра на ПК (нужен gcc в PATH, есть).
- `pio run -e lamp` / `-t upload` / `pio device monitor` — основная прошивка.
- `pio run -e panel_test -t upload` — тест панелей (docs/lamp/bringup.md).
- `pio run -e lamp_ota -t upload` — прошивка по Wi-Fi на `indicator.local`.

Проверка изменений: минимум `pio test -e native` и `pio run -e lamp -e panel_test`.

## Правила
- Логику, которую можно отделить от железа, писать в `lib/indicator_core` (без `Arduino.h`) и
  покрывать тестом в `test/test_core`. Железо — только в `src/hw`, `src/net`.
- Пины и константы сборки — только в `include/config.h`; при смене пинов обновить
  таблицу в `docs/lamp/hardware.md`.
- Все каналы управления (USB, UART, HTTP) используют один текстовый протокол
  (`Command.h`, docs/lamp/protocol.md). Новая функция = новая команда + строка в протоколе.
- Память ESP32 ограничена: DMA-буфер панелей 16 КБ × бит цвета (6 бит = 96 КБ), кадр 48 КБ.
  Не заводить ещё полноэкранные буферы; двойную буферизацию не включать.
- Шина I2C общая (MPU6050, позже INA226): доступ из разных задач — через мьютекс.
- Документация на русском, комментарии в коде — на английском, коротко.
- Решения, которые меняют архитектуру, фиксировать ADR в `docs/decisions/` (шаблон там же).
- Замеры (масса, ток, частота) — в `docs/lamp/measurements.md`, не в чате.
- `legacy/` не трогать.
